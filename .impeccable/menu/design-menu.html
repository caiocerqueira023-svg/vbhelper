01 / DIAGNOSIS

Five reasons it reads generated

measured on the current build

The problem is not the palette or that it is dark. Official Digimon UI is also dark, dense, and neon-tinged. The difference is that every element there carries information, and here almost every element is a decoration applied evenly to everything.

Tell 01

Every surface is the same box

Search field, filter chips, icon buttons, tiles: one pale fill, one 1dp stroke, one cut corner. Nothing in the shape language says "this is a section", "this is a value", "this is the thing you are about to tap" — so the eye finds no hierarchy and reads the screen as a component demo.

47 BorderStroke sites · 112 CutCornerShapes across 15 radii · 20 dividers · pills, rounded Cards and 47 default-rounded AlertDialogs mixed in
Tell 02

Everything sits on one plane

Zero shadows, zero blurs, zero radial gradients: depth is faked with 116 alpha tweaks, so the command deck, the partner slab and the background all read at the same distance. Official UI puts one lit glass plate over a live world and lets the world be the depth.

shadow() 0 · blur() 0 · radialGradient 0 · elevation used twice in the whole app
Tell 03

Numbers and names are typeset like prose

Values, levels and counts take the body size and the body font, names are clipped to “Omegamon Zw…” outside the tile that owns them, and nothing is aligned in a column. In the references the number is always the loudest thing on the row and always in the same place.

5 font families on all 15 roles · 27 distinct sp sizes · 53 inline fontSize overrides · 91 TextOverflow calls across 1,193 Text()
Tell 04

The world has no backdrop

The diorama floats in pure black with no ground plane past its edge, no horizon, no fog, no light source. A shipped Digimon game establishes the world before it draws a single panel — and that world is what makes the panels feel like a device resting on top of it.

Home shell: edge-to-edge 3D, no atmosphere layer · panel chrome is 100% opaque so nothing reads as glass
Tell 05

States are a sentence in a box

Empty state: no illustration, no next action, no instruction — just “Nothing to see here” centred in a rectangle. Official UI never leaves a screen without telling you what it wants, because a controller has buttons and a touch screen has a thumb, and both need to know what to do next.

≥8 header/panel treatments · 5 chip geometries · 2 icon sets · 6 stat/progress components with different track heights

Track A

Foundation — how information is built

fixes tells 01, 02
01
Time Stranger · 2025 · the current flagship

Band-plate panels

A panel becomes a banded plate: a hatched header strip carrying the label and its value, hairline-ruled rows flush beneath it, and a footer that carries the action. The header is a band, not a border around a box.

  • band 34–40dp · 45° hatch 6% white
  • rows 30dp · 1dp rule 8%
  • radius 2dp · stroke 12% · fill 88% ink
Replaces
Eight different outlined boxes where a section header and a content row look identical.
Lands in
Settings · Home partner slab · Dex · Storage · Arena briefing · Lorebook
Cost
MPanel kit
02
Time Stranger + Cyber Sleuth

Data rows, not stat cards

Numbers live in a column: micro label left, dotted leader, tabular figure right-aligned on a faintly tinted band. One row per fact, 30dp tall, no card, no rounding, no emoji in the data.

  • label 10sp · 700 · +0.09em
  • leader 1dp dotted · 22%
  • value column 4% tint · tabular
Replaces
One card per value, numbers that never line up, and emoji standing in for a data vocabulary.
Lands in
Partner details · Dex facts · Storage counts · Arena stats · battle result
Cost
MRow kit
03
Cyber Sleuth + Time Stranger

Two type voices, one numeral standard

One condensed display voice for titles and big numerals, one neutral data voice for everything readable, and tabular figures wherever numbers are compared. Oxanium stops being the body font.

  • display 22–28sp · 700 · skew −6°
  • data 14 / 13 / 12 · one family
  • 27 sp values → 6 role values
Replaces
Oxanium at five weights doing every job, 53 inline size overrides, and level numbers typeset like body copy.
Lands in
App-wide — one type file and one theme mapping
Cost
SType ramp
04
Time Stranger · the role split

One warm signal, grounded neutrals

Neutrals carry 90% of the screen. Exactly one warm signal — amber — marks current state and the primary action. Saturated colour survives only inside attribute badges, where it means something. Purple leaves the UI; cyan keeps one job: live vital data.

  • ground #0B0D12 · panel #12151C
  • signal #F0A63C · one job only
  • 91 hexes → ~18 tokens
Replaces
Cyan doing five jobs at once — selection, value, energy, link, decoration — so nothing on screen reads as chosen.
Lands in
Theme + every screen. All four saved palettes keep working as re-tints of the same roles.
Cost
MToken set

Selected plate & name bib

Unselected tiles are flat and quiet. The selected one takes a 2dp signal border, a warm wash and a name bib inside the plate that inverts to paper — so selection is unmistakable and long names wrap instead of truncating.

  • selected 2dp signal + 6% wash + 2dp lift
  • bib 9.5sp inside the plate · wraps to 2
  • unselected: no border, 12% fill
Replaces

System — what makes it feel shipped

09
Time Stranger · every overlay in the game

Glass over the world

Chrome floats on the diorama as dark glass — 84% ink with a light top edge and a blur — instead of opaque slabs that delete the 3D scene. And the scene gets its horizon back, because glass only reads as glass when there is something behind it.

  • fill rgba(10,13,18,.84) + blur 12
  • top edge 1dp white 18%
  • no drop shadows, ever
Replaces
Flat opaque panels that hide the world, and a black void where a sky, ground plane and fog should be.
Lands in
Home shell · World · battle HUD · partner sheet
Cost
MShell + scene

All four references · the console convention

Context footer bar

A console always tells you what the current screen wants. One persistent 44dp strip: what this screen does on the left, the live actions on the right, updated as focus and selection change. It also gives empty, loading and error states somewhere to speak from.

  • 44dp strip · 10.5sp instruction 66%
  • up to 3 prompts · 17dp disc
  • updates on focus and selection
Replaces
Screens that never state their own task, and empty states that answer with “Nothing to see here”.
Lands in
Every screen; it replaces the loose helper text scattered around

Chrome vocabulary: plates, chevrons, brackets

Replace the defaults with a small, repeatable set of edge shapes: tab plates that connect to their panel, gold angular chevrons for paging, L-brackets for corners, capped dividers. One vocabulary instead of two icon sets and five chip geometries.

  • chevron from two 45° bars
  • bracket arms 9dp · 2dp

Cyber Sleuth: Hacker's Memory · Field Guide

Header band with live counters

The screen header is one band: the title in the display voice, then two live counters right-aligned in signal numerals, then the single action. Not a toolbar that has to carry every optional control the screen might need.

  • band 52dp · hatch 5.5% white
  • counters 9sp labels + 16sp numerals
  • one action, 26dp
Replaces
The TopBanner's eleven optional parameters and eight competing header treatments — a header that must carry everything ends up saying nothing.

Recommendation

If you only do three

  1. Band-plate panels. Fixes the flat, uniform-box problem everywhere at once, and every later move sits inside a panel.
  2. One warm signal. Fixes the cyan-does-everything problem. Selection starts to read as selection.
  3. Attribute badges. Fixes the identity problem. This is the one that stops it looking like a generic sci-fi tracker and starts it looking like Digimon.

Then, in this order: 02 (data rows) → 10 (footer bar) → 08 (selection) → 07 (portrait plate) → 09 (glass) → 12 (header band) → 03 → 11 → 06. Track A + B together is roughly a week of interface work; Track C is another few days.

Judgement

What I would not copy

Cyber Sleuth's glossy chrome-blue.It is a 2014 Vita language; on Android it dates the app instantly.

Survive's torn-paper ribbons and highlighter yellow.That is a different game's identity, not a Digimon one.

The literal LT/RB key prompts.Keep the idea of a hint line; translate the glyphs to touch.

Radial for everything.The dial earns its place once, on Home. Everywhere else it would be a costume.
